# HealthSeq-NF Foundations Path

HealthSeq-NF Foundations develops practical workflow skills through seven
progressive lessons.

## Project Sequence

```text
GitHub and Codespaces
→ terminal basics
→ one Nextflow process
→ file inputs and outputs
→ connected processes
→ parameters
→ reusable multi-process pipeline
→ Git and GitHub
→ extension readiness
```

## Lessons

1. `lessons/01_first_nextflow.md`  
   Run one process and inspect its output.

2. `lessons/02_process_inputs.md`  
   Pass a file into a process.

3. `lessons/03_channels_and_data_flow.md`  
   Connect two processes through a named output channel.

4. `lessons/04_parameters.md`  
   Change workflow behavior without rewriting process logic.

5. `lessons/05_small_pipeline.md`  
   Run a reusable three-process pipeline and publish its final report.

6. `lessons/06_git_and_github.md`  
   Record meaningful project changes with Git and GitHub.

7. `lessons/07_prepare_for_applied.md`  
   Review the project and identify possible extensions.

## Project Outcome

After completing the lessons, learners should be able to:

- run and explain a Nextflow workflow;
- identify inputs, outputs, channels, and dependencies;
- use file and value inputs;
- override parameters;
- publish selected outputs;
- troubleshoot simple workflow errors;
- create meaningful commits;
- extend the project for another scientific use case.
